# FIVE NIGHTS AT AJAN

A small, original, browser-playable survival-horror game inspired by the security-room survival genre.

## Play

Open `index.html` in a modern browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` → `/ (root)`). Once Pages finishes deploying, the game will be available at:

https://contdefault03-spec.github.io/FIVE-NIGHTS-AT-AJAN/

## Controls

- **A / D** — toggle left/right doors
- **Q / E** — toggle left/right hall lights
- **C** or **Space** — open/close security cameras
- **Escape** — close the camera monitor
- You can also use the on-screen buttons.

## Current prototype

- First-person security office rendered on a canvas
- Two roaming threats, camera feeds, door and light controls
- Power management and usage meter
- Five increasingly difficult nights, survive until 6 AM
- Performance mode to reduce visual effects

This is an early playable prototype. Visuals and sound are intentionally lightweight and do not require external assets or downloads.
